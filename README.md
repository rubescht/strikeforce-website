# Strikeforce Cyber website

Static site for Strikeforce Cyber (a Code Black Group company). No build step.

- `index.html` – the full single-page site
- `assets/` – logo, AI shield video and poster, icons, social share image
- Hosted on Render as a static site from the `main` branch (publish directory `./`). Every push to `main` redeploys automatically.
